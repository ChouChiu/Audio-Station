## 阅读建议

- 想了解一次任务如何穿过 GUI、后台线程和处理管线：先阅读“架构与数据流”。
- 想调整参考对消效果：阅读“参考对消实现”，并优先验证对齐而不是盲目提高强度。
- 想修改完整舞台自动排布：同时阅读“完整舞台实现”和架构中的跨功能编排边界。
- 想增加模型或调整推理：阅读“AI 人声分离实现”。
- 准备提交代码或构建发布包：阅读“开发、测试与发布”。

文档描述以当前 Python 实现为准。合成回归结果不作为真实音乐质量结论。
